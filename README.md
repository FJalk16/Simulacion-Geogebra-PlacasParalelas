# Simulación y protocolo de construcción

Este repositorio contiene los materiales del proyecto:

- **`protocolo/`**: Documento con el protocolo de construcción.
- **`simulacion/`**: Archivo `.ggb` de la simulación, para abrir con **GeoGebra** (versión de escritorio o web).
- **`pruebas/`**: Hoja de cálculo Excel con los datos de las pruebas realizadas.

## Cómo usar la simulación
1. Descarga el archivo `.ggb`.
2. Ábrelo con [GeoGebra](https://www.geogebra.org/download) (o súbelo a la versión web).
